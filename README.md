# SRAI Book 1 — Mathematical Foundations

This repository contains the controlled computational and educational production units for **SRAI Book 1 — Mathematical Foundations**.

SRAI — Statistics, Reasoning and Artificial Intelligence — connects mathematical and statistical reasoning with reproducible computation, machine learning, responsible artificial intelligence and defensible decision-making.

Each production unit is self-contained and may include its notebook, controlled documents, Python utilities, requirements, validation scripts, release evidence and presentation assets. Open the production-unit README for exact paths, verification instructions, review status and known limitations.

## Validation

Use the verification instructions provided inside the relevant production-unit README. Where a requirements file and automated validation command are supplied, create an isolated environment, install the pinned dependencies and run that unit's documented checks from its own directory.

Checksums, validation reports and evidence records are retained within the applicable production unit. A successful computational check does not replace the stated review and authorization status.
