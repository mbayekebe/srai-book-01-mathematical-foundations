# Lesson 2 — Sets, Logic, Relations and Functions

**Production unit:** PU-B01-C02
**Book:** Book 1 — Mathematical Foundations
**Notebook:** M1_N02_sets_logic_relations_functions.ipynb

Sets determine what belongs. Logic determines truth conditions. Relations determine what is connected. Functions determine how declared inputs map to outputs. Lesson 2 connects these foundations to data filters, databases, knowledge systems, algorithms and transparent decision rules.

## Learning outcomes

- distinguish membership from subsethood;
- compute and interpret core set operations;
- evaluate logical connectives and material implication;
- distinguish relations, partial functions and total functions;
- translate predicates into reproducible filters;
- document universes, domains, codomains, missing-data rules and decision reasons.
